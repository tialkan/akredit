# Resmî kaynak belgeler

YÖKAK, program akreditasyon kuruluşları ve mevzuat belgelerinin resmî sitelerinden indirilmiş kopyaları buraya konur. Dosya adı: `<kurum>-<belge>-<tarih>.pdf`. Her belge için `kaynaklar.json` içine kaynak adresi, indirme tarihi ve SHA-256 özeti yazılır. Çerçeve verisi (packages/cerceveler) ölçüt metnini yalnız bu belgelerden alır.
