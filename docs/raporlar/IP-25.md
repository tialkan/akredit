# İP-25 raporu: MCP sunucusu

- **Dal:** `ip/25-mcp`
- **Durum:** inceleme
- **Test:** `@akredit/mcp` 21 test (1 dosya), hepsi geçiyor; `pnpm verify` temiz.

## Özet

`apps/mcp` (`@akredit/mcp`), Claude ve diğer YZ istemcilerinin akredit.org verisiyle çalıştığı Model Context Protocol sunucusudur. Araçlar REST'i değil doğrudan `@akredit/servis` işlevlerini çağırır: kiracı işlemi, kapsam zinciri, `@akredit/yetki` denetimi, ret günlüğü ve zod doğrulaması servisteki gibi işler. Kimlik API anahtarıdır (`akr_…`); yetki = kişinin rolleri ∩ anahtar kapsamı. Karar veren, politika imzalayan ya da dışarı gönderen araç yoktur.

- **Uzak:** `akredit-mcp --http [kapı]` → durumsuz Streamable HTTP (yalnız `POST`, JSON yanıt, ileti dizisi). Her istek `Authorization: Bearer akr_…` taşır; anahtarsız/geçersiz/iptal/süresi dolmuş anahtar 401, izinsiz `Origin` 403, hız sınırı 429 (servisin `HizSiniri`). İşleyici `Request → Response` olduğu için Next.js rotasına da bağlanabilir.
- **Yerel:** `AKREDIT_ANAHTARI=… akredit-mcp` → stdio, satır başına bir ileti. Anahtar her araç çağrısında yeniden doğrulanır (iptal hemen etkili).
- Veritabanı: `AKREDIT_VT_ADRES` (PostgreSQL) ya da `AKREDIT_VT_DIZIN` (PGlite).

## Araçlar

`ben`, `kanit_ara`, `kanit_oku`, `oneri_listesi`, `oneri_olustur`, `rapor_listesi`, `rapor_oku`, `rapor_denetle`, `program_listesi`, `ders_listesi`, `matris`, `olcme`. Tanımlar, gereken yetki ve JSON şemaları `apps/mcp/ARACLAR.md`'de; belge araç tanımlarından üretilir (`pnpm --filter @akredit/mcp araclar`), test depodakinin güncel olduğunu denetler.

| Yüksek risk insanda | Dış gönderim MCP'den önerilemez; risk `etkinRisk` ile türün riskinden düşük yazılamaz; öneri `onay_bekliyor` döner | `olgunluk_duzeyi` + `risk: dusuk` → `yuksek` |

## Bağımlılık

Yeni dış bağımlılık yok. MCP SDK yerine protokolün gereken kısmı (JSON-RPC 2.0, initialize/ping/tools) elle yazıldı: yüzey küçük, her davranış testli, ağsız çalışır. Araç girdileri zod 4 `toJSONSchema` ile şemaya çevrilir.

## Kararlar

- MCP araçları REST yerine servisi doğrudan çağırır (aynı süreçte, aynı veritabanı bağlantısı). Uzak sunucu, web sunucusu gibi veritabanına bağlanır.
- Politika motoru MCP öneri yazımında çalışmaz; kişinin imzaladığı politika işçi turunda (İP-13) uygulanır. Böylece MCP çağrısı hiçbir koşulda aynı işlemde karar üretmez.
- `rapor_denetle` çekirdeğin `raporDenetle`'sini aktörün okuyabildiği kanıtlarla çalıştırır; alıntı için yalnız atıf yapılan kanıtların parçaları okunur.
- `matris`/`olcme` yalnız kayıtlı ya da ölçme motorunca hesaplanmış değerleri döndürür; sonuç yoksa liste boş.

## Bilinen sınırlar

- HTTP sunucusu oturum kimliği (`Mcp-Session-Id`) ve SSE akışı kullanmaz (durumsuz, JSON yanıt); bildirim gönderimi yok.
- `apps/web`'de `/mcp` rotası yok (bu İP'nin yolu değil); `mcpHttpIsleyici` doğrudan bağlanabilir.
- OAuth yetkilendirmesi yok; yalnız API anahtarı.
- Kişisel veri maskelemesi MCP çıktısında ayrıca yapılmaz: kanıt metni kanıt hattının kaydettiği hâliyle döner (`kisiselVeri` alanı görünür). Yurt dışı sağlayıcıya giden içerik için kurum politikası İP-27/28'de ele alınmalı.
- Hız sınırı süreç içi bellektedir (İP-12 ile aynı).
