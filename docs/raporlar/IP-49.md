# İP-49 raporu: Herkese açık Akredit MCP sunucusu ve tanıtımı

- Dal: `ip/49-acik-mcp`
- Durum: inceleme
- Test: `@akredit/acik-mcp` 13 test; web site testleri (kurallar, yol haritası) geçiyor.

## Özet

Yeni paket `apps/acik-mcp` (`@akredit/acik-mcp`): hesapsız, durumsuz, salt okuma MCP sunucusu. Web uygulamasında `/mcp` rotası olarak çalışır (`apps/web/src/app/mcp/route.ts`), ayrı hizmet yoktur; bu yüzden `infra/coolify/docker-compose.yml` değişmedi. Aynı araçlar stdio ile yerelde de çalışır (`akredit-acik-mcp`).

İP-25'teki kurum MCP'sinden (`apps/mcp`, API anahtarı, servis katmanı) ayrıdır ve ona dokunmaz.

## SDK ve protokol

- `@modelcontextprotocol/sdk` 1.32.2 (npm `latest`, 2026-10-23; MIT). SDK'nın desteklediği en yeni protokol 2025-11-25 (ayrıca 2025-06-18, 2025-03-26, 2024-11-05).
- MCP belgelerinin güncel sürümü 2026-07-28 (modelcontextprotocol.io, transports sayfası): oturumsuz, istek başına üst veri. SDK 1.32.2 bunu henüz uygulamıyor; belge eski (initialize'lı) sürümlerle geriye uyum yolunu tarif ediyor. Sunucu bugünkü istemcilerin kullandığı initialize'lı sürümlerle konuşur; SDK 2026-07-28 desteği getirince sürüm yükseltilmeli.
- Taşıma: `WebStandardStreamableHTTPServerTransport`, `sessionIdGenerator: undefined`, `enableJsonResponse: true`; her POST için yeni sunucu.
- Yeni bağımlılık gerekçesi: protokol sürüm uyumu ve istemci testinin resmî uygulamayla yapılması. Web'e iş alanı paketi bağımlılığı eklendi.

## npm yayınlama (derleme hazır, yayın yapılmadı)

Node, `node_modules` içindeki `.ts` dosyalarında tip ayıklama yapmaz; paket JavaScript olarak yayınlanır.

- `pnpm --filter @akredit/acik-mcp build` (`scripts/derle.ts`): `tsc -p tsconfig.build.json` bu paketi ve kullandığı iş alanı paketlerini (cekirdek, cerceveler, olcme, yz) `dist/` altına derler (`rewriteRelativeImportExtensions`, `.d.ts` ile). `@akredit/<paket>` belirteçleri derlenmiş kopyaya göreli yola çevrilir; gömülmeyen bir iş alanı paketi görülürse derleme durur (`test/derle.test.ts`). Dış bağımlılık yalnız MCP SDK ve zod. Esbuild gibi yeni bağımlılık eklenmedi.
- `package.json`: `private` kaldırıldı; iş alanı paketleri `devDependencies`'e taşındı (yayımlanan pakette kurulmaları gerekmez, gömülüdür); `files: ["dist"]`, `prepack` derler; `publishConfig` yayında `bin` ve `exports`u `dist`e çevirir (pnpm `publishConfig` alanlarını uygular, yayın `pnpm publish` ile yapılmalı, `npm publish` bu alanları uygulamaz). İş alanında `bin`/`exports` kaynak `.ts`'e bakmaya devam eder.
- Deneme (2026-10-30): `pnpm pack` (149 dosya), `npx -y --package=./akredit-acik-mcp-0.1.0.tgz akredit-acik-mcp` boş dizinde stdio ile: `initialize` (protokol 2025-06-18), `tools/list` 7 araç, hepsi `readOnlyHint: true`, `tools/call` yanıt verdi. Yayımlanınca tek `bin` olduğu için `npx -y @akredit/acik-mcp` aynı komutu çalıştırır.
- Kalan (kurucu kararı): npm'de `@akredit` kapsamının alınması ve `pnpm --filter @akredit/acik-mcp publish --access public`. Pakete kök `LICENSE` kopyası eklendi; npm sayfası için kısa bir `README.md` yayından önce yazılmalı.
