# İP-03 raporu: Yapay zekâ katmanı ve güvenceler

## Özet

`@akredit/yz` paketi sağlayıcıdan bağımsız YZ katmanını ve "uydurmaz" güvencelerini kodla uygular. Bütün testler sahte `fetch` ya da sahte sağlayıcıyla, ağsız çalışır.

## Dosyalar (`packages/yz/`)

| Dosya | İçerik |
|---|---|
| `src/saglayici.ts` | İç mesaj/araç biçimi, `Saglayici`, `YzHatasi`, `InsanGerekliHatasi` |
| `src/http.ts` | Zaman aşımı, 429/5xx'te `retry-after`'a uyan üstel bekleme, Türkçe hata eşlemesi |
| `src/saglayicilar/openai-uyumlu.ts` | EVREN, vLLM, SGLang, Ollama, OpenAI, OpenRouter (HAZIRLAR CLI ile aynı adresler), gömme |
| `src/saglayicilar/anthropic.ts` | Messages API, `fetch` ile |
| `src/saglayicilar/sahte.ts`, `kayit.ts` | Senaryolu sahte sağlayıcı; JSON kasete kayıt/oynatma |
| `src/yapilandirilmis.ts` | zod → JSON şema, yerel ya da istem yolu, 2 onarım, sonra `InsanGerekliHatasi` |
| `src/ajan.ts` | Araç döngüsü: okuma/oneri çalışır, `onay_gerektirir` bekleyen onay olur, `yasak` reddedilir ve modele tanıtılmaz; tur sınırı, kısaltma, iptal, olaylar |
| `src/guvence/atif.ts` | Kısaltma duyarlı cümle bölme, atıf/kanıt/konum/alıntı denetimi, `atifsizlariIsaretle` |
| `src/guvence/sayi.ts` | Türkçe sayı, yüzde, tarih çıkarma; dayanaksız sayı raporu |
| `src/guvence/kvkk.ts` | TCKN (sağlama), telefon, e-posta, IBAN (mod-97), öğrenci no, Türkçe ad eşleşmesi; kayıpsız geri çevirme |
| `src/guvence/istem-kalkani.ts` | Veri etiketi, etiket taklidi temizleme, talimat kalıbı tespiti |
| `src/guvence/politika.ts` | İzinsiz yurt dışı sağlayıcı reddi; izinliyse zorunlu maskeleme sarmalayıcısı |
| `src/olcum.ts` | Süre, belirteç, tahmini maliyet olayı |
| `src/gorevler/` | `kanit-siniflama`, `toplanti-bilgisi` (adlar maskeli gider; tarih ve katılımcı sayısı kaynakta yoksa reddedilir) |
| `src/degerlendirme/` | Düzenek, kurgu altın örnekler, `pnpm --filter @akredit/yz degerlendir --gorev … --saglayici sahte` |

## Test

6 dosya, 100 test. `src/guvence` satır kapsamı %100 (eşik %90, `vitest run --coverage` ile zorunlu). `pnpm verify` temiz.

## Bağımlılık ve ortak dosyalar

- `@vitest/coverage-v8` (MIT), yalnız `packages/yz` geliştirme bağımlılığı: kapsam ölçütünü denetlemek için. `pnpm-lock.yaml` buna göre güncellendi.

## Bilinen sınırlar

- Olgusallık ölçütü sezgiseldir (≥3 kelime, soru/başlık/EKSİK değil); çağıran kendi ölçütünü verebilir.
- Sayı denetimi takvim geçerliliğine bakmaz (31.02 tarih sayılır).
- Metinde önceden `[KİŞİ-n]` gibi yer tutucu yazımı varsa geri çevirmede karışabilir.
- Görev çıktısındaki `[KİŞİ-n]` yer tutucularını geri çevirmek çağıranın işidir (`tutanagiMaskele` eşlemeleri verir).
- Gerçek modelle değerlendirme yapılmadı (kapsam dışı, anahtar gerektirir).
