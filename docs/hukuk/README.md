# Akredit hukuk paketi (taslak)

> **TASLAK — avukat incelemesi gerektirir.** Bu belgeler Akredit tarafından hazırlanmış taslaklardır; hukuki görüş değildir, bağlayıcı değildir. Kurumun hukuk birimi ya da bir avukat incelemeden yayımlanmamalı, imzalanmamalıdır. Kaynaklar ve doğrulanamayan noktalar: [kaynaklar.md](kaynaklar.md).

| [kvkk-uyum-analizi.md](kvkk-uyum-analizi.md) | Roller, hukuki sebepler, riskler ve ürün içi uyum boşlukları |
| [veri-isleme-sozlesmesi.md](veri-isleme-sozlesmesi.md) | Kurum (veri sorumlusu) ile işletmeci (veri işleyen) arasında sözleşme şablonu |
| [aydinlatma-metinleri.md](aydinlatma-metinleri.md) | Kullanıcı, öğrenci verisi ve anket katılımcısı aydınlatma metinleri |
